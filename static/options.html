Data Preview

tldr has no hosted backend. Data leaves Chrome only when the configured LLM, Pinboard, Readwise, or GoodLinks flow runs.

Stored locally

  • Saved item title, URL, domain, excerpt, tags, and sync status in Chrome local storage.
  • API keys and integration tokens in Chrome local storage, shown here only as configured or missing.

Synced settings

  • LLM host, model, privacy mode, tag preferences, and integration flags in Chrome sync storage.
  • No API key, Pinboard token, or Readwise token is sent to the LLM payload.
Remote API calls use your configured endpoints. The extension does not load remotely hosted executable code.
